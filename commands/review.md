# Task: Code Review

Review the code that is being pointed at explicitely or if not, then the recent changes by viewing the latest git commits. 

Also look for how this code is integrated into the project and conduct the review with the interactions in mind.

## Questions
- How would a senior expert approach this?
- Which issues would he spot?
- Which potential problems would he point out?

## Criteria
- Optimize for simplicity, least amount of code necessary, lean architecture
- Point out brittle, redundant code

Create a code review report with items ordered by criticality
