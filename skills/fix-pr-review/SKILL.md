---
name: fix-pr-review
description: Review a PR conversation and implement fixes for valid findings. Use this skill whenever the user asks to "fix PR review findings", "address PR comments", or "implement PR feedback".
---

1. Review PR reviewer findings from the PR conversation (or report review status and exit if no findings).
2. Evaluate each finding if valid regarding higher level project goals, PRDs and guidelines.
3. Implement fixes for each valid finding.
4. Respond and resolve each finding in the PR conversation with short rationale for the fix or rejection.
